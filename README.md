# เส้นทางนักเทคโนโลยีสุขภาพ (Health Tech Board Game)

บอร์ดเกมบนเว็บสำหรับโปรโมทหลักสูตรเทคโนโลยีสุขภาพ เล่นด้วยมือผ่านเว็บแคม (MediaPipe Hand Landmarker) หรือเมาส์/แตะจอ

- จีบนิ้วโป้งกับนิ้วชี้ = หยิบ / กดปุ่ม, แยกนิ้ว = วาง
- ทอยเต๋าเดินบนกระดาน 20 ช่อง ผ่านภารกิจตามสถานี แล้วสรุปผล "คุณเหมาะกับสาย…" พร้อม QR หลักสูตร
- สถานีครบ 5 สถานี: ห้องเครื่องมือแพทย์, ศูนย์ซ่อมบำรุง, แล็บ IoT, ห้องข้อมูลสุขภาพ, ป้อมไซเบอร์ (สุ่มเล่น 3 สถานีต่อเกม)
- รองรับทุกขนาดจอ กระดานวิ่งรอบขอบจอ จัดแนวตั้ง/แนวนอนอัตโนมัติ
- ตั้งค่าได้ที่ `CONFIG` ตอนต้นสคริปต์ใน `index.html` (ลิงก์ QR, จำนวนสถานี, เวลาต่อสถานี)
- กด Esc เพื่อกลับหน้าแรก
- โหมดกล้องต้องเปิดผ่าน https (เช่น GitHub Pages)
